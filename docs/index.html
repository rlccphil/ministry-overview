Administrator note

This page frames the Google Apps Script deployment. For the embed to work, the script's doGet must call setXFrameOptionsMode(HtmlService.XFrameOptionsMode.ALLOWALL) and the deployment must be published with Who has access: Anyone. After changing the script, redeploy (Deploy → Manage deployments → edit → New version) and refresh this page. Full notes are in README.md.
